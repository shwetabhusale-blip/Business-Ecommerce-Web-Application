1. Install Node.js LTS from https://nodejs.org/
2. Extract this ZIP.
3. Open the extracted folder in Visual Studio Code.
4. Open VS Code Terminal: Terminal > New Terminal.
5. Run: npm install
6. Run: npm start
7. Terminal will show: ShopEase running at http://localhost:3000
8. Open Chrome/Edge and enter: http://localhost:3000
9. Register a user, login, add products, open Cart, checkout, and see Order History.

IMPORTANT:
This is an academic working prototype. User and order data are kept in memory, so they reset when the Node server restarts. Do not use real passwords or real customer information.
